Script ini menghitung luas berbagai bentuk geometris berdasarkan input pengguna.
Pengguna dapat memilih dari bentuk berikut:
1. Segitiga
2. Lingkaran
3. Persegi Panjang
Bergantung pada pilihan pengguna, script akan meminta dimensi yang diperlukan
dan kemudian menghitung serta menampilkan luas bentuk yang dipilih.
Fungsi:
    Tidak ada
Penggunaan:
    Jalankan script dan ikuti petunjuk di layar untuk memasukkan dimensi yang diperlukan
    untuk bentuk yang dipilih. script kemudian akan menampilkan luas yang dihitung.
Contoh:
    Jika pengguna memilih '1' untuk Segitiga, mereka akan diminta untuk memasukkan alas dan tinggi.
    script kemudian akan menghitung dan menampilkan luas segitiga.
Catatan:
    script menggunakan `eval` untuk mengurai input pengguna, yang dapat menjadi risiko keamanan jika input
    tidak disanitasi dengan benar. Disarankan untuk mengganti `eval` dengan alternatif yang lebih aman
    seperti `float` atau `int` untuk mengurai input numerik.
